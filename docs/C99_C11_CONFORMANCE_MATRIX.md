# C99/C11 Conformance Matrix

This matrix is the working checklist for the first production ISO C target.
It tracks language conformance, not performance or code-size quality.

Status values:

- Supported: implemented and covered by regression tests.
- Partial: implemented for common/currently tested cases, but not complete.
- Unsupported: known missing functionality.
- Untested: implementation status is unclear or lacks focused coverage.

## Summary

Current target:

```text
C99/C11 freestanding language conformance first.
Hosted library conformance is out of scope for the first pass.
```

Current baseline:

```text
make stage2: pass
make test: pass, stage0 10047/10047 and stage1 10047/10047
make test-conformance-c99: pass, 2290/2290
make test-conformance-c11: pass, 2302/2302
make test-conformance-c17: pass, 2302/2302
make test-conformance-c23: pass, 2303/2303
make test-conformance-external-torture: pass, 220/220
make test-sanitize: pass, 10039/10039 under ASAN+UBSAN
make test-installed-smoke: pass
make test-release-gates: pass
sqlite smoke on Darwin arm64: pass
```

Current standards split:

- C99 and C11 remain the first claimed production language targets.
- C23 is still measured explicitly, but not yet claimed as a full production
  language target.
- The remaining `-std=c11`-only manifest entries are now intentionally
  standard-gated rather than missing promotions:
  pre-C23 identifier acceptance, pre-C23 empty-initializer rejection,
  pre-C23 declaration-after-label rejection, the pre-C23 static-assert
  message requirement, and the C11-specific `__STDC_VERSION__` check.
